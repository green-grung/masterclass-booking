# CI/CD Pipeline для Laravel приложения "ОчУмелые ручки"

## Структура веток
- `main` – продакшен (защищена, требует PR и ручного аппрува)
- `uat` – приёмочное тестирование
- `dev` – разработка

## Переменные окружения
Файлы: `.env.dev`, `.env.uat`, `.env.prod`, `.env.ci` (последний в репозитории).
Обязательные переменные: `APP_NAME`, `APP_ENV`, `APP_DEBUG`, `APP_URL`, `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`, `APP_KEY` (может быть пустым – генерируется в пайплайне).

## Шаги пайплайна (GitHub Actions)

### 1. Тесты и покрытие
- Запуск PHPUnit с SQLite in-memory.
- Проверка покрытия кода: должно быть ≥ 50%. Иначе пайплайн красный.

### 2. Статический анализ (PHPStan/Larastan)
- Уровень 5, проверка папок `app`, `tests`.
- Любая ошибка (не warning) останавливает пайплайн.

### 3. Линтинг (Laravel Pint)
- Пресет `psr12`.
- Режим `--test` – только проверка, без автоисправления.
- Нарушение правил → пайплайн красный.

### 4. Симуляция деплоя
- Выполняется только если предыдущие шаги успешны.
- Копирует соответствующий `.env.xxx` в `.env`.
- Выводит сообщение о среде.
- Для ветки `main` требуется **ручной аппрув** (GitHub Environment `production` с ревьюерами).

### 5. (Дополнительно) Уведомление по email
- Отправляется maintainers при падении пайплайна.

## Запуск пайплайна
Пайплайн запускается автоматически при push или pull request в ветки `dev`, `uat`, `main`.

## Как проверить локально
```bash
# Тесты с покрытием
./vendor/bin/phpunit --coverage-text

# Статический анализ
./vendor/bin/phpstan analyse

# Линтинг
./vendor/bin/pint --test
